Sweep Breakpoint Demo
Fixed 600px banner — overflows when viewport < 600, responsive when ≥ 700

This fixture is intentionally breakpoint-sensitive. Horizontal overflow appears only on viewports narrower than ~600px.

Sweep from 320:900:80 should catch the transition; single preset desktop (1440) would miss it if it were only overflow, and sweep shows exactly which widths are affected.

Height is stable 900 for sweep widths. Overflow detection uses scrollWidth vs viewportWidth.
